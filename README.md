# پروژه تحلیل شبکه اجتماعی (ریاضیات گسسته) 🌐
این پروژه به منظور تحلیل ساختار و ویژگی‌های یک شبکه اجتماعی با استفاده از نظریه گراف‌ها و الگوریتم‌های مرتبط طراحی شده است.

## 👥 اعضای تیم
- **آلان حاتمی** (مدیر پروژه و مسئول تحلیل پیشرفته و بصری‌سازی)
- **سبحان رئیسی** (مسئول ساختار داده و پیاده‌سازی BFS/DFS)
- **محمد مهدی قادری** (مسئول پیاده‌سازی الگوریتم دایکسترا و معیارهای مرکزیت)

## 🎯 اهداف پروژه
- پیاده‌سازی ساختار گراف از صفر.
- تحلیل مسیرهای کوتاه بین کاربران با الگوریتم‌های **BFS** و **Dijkstra**.
- محاسبه معیارهای مرکزیت (**Degree**, **Betweenness**, **Closeness**).
- تشخیص اجتماعات (Community Detection) و تحلیل ضریب خوشه‌بندی.
- بصری‌سازی گراف و تحلیل توزیع درجه گره‌ها.
