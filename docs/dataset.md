# 📊 مستندات دیتاست (Dataset Documentation)

## 📁 معرفی منبع
داده‌های مورد استفاده در این پروژه از مجموعه داده‌های **SNAP (Stanford Network Analysis Project)** استخراج شده است. این دیتاست مربوط به شبکه اجتماعی **Facebook** بوده و شامل "Ego-networks" است.

- **نام فایل:** `social_network.csv`
- **فرمت:** Edge List (لیست یال‌ها)
- **تعداد گره‌ها (Users):** 4,039
- **تعداد یال‌ها (Connections):** 88,234

## 📐 مشخصات ساختاری (Graph Topology)
این شبکه دارای ویژگی‌های زیر است:
1. **بدون جهت (Undirected):** یال‌ها نشان‌دهنده رابطه دوستی دوطرفه هستند.
2. **بدون وزن (Unweighted):** تمام ارتباطات دارای ارزش یکسان هستند.
3. **متراکم (Dense Clusters):** وجود حلقه‌ها و مثلث‌های زیاد که نشان‌دهنده جوامع واقعی انسانی است.

## 🛠 فرآیند پیش‌پردازش
- حذف گره‌های تکراری (Self-loops).
- یکنواخت‌سازی فرمت ورودی به صورت ستون‌های `source` و `target`.
- نمونه‌برداری (Sampling) برای بصری‌سازی: به دلیل حجم بالای یال‌ها، برای رسم نمودار شبکه از زیرگراف‌هایی با اندازه بهینه استفاده شده است تا خوانایی حفظ شود.
